# Performance and tactile verification

The reported defect came from gesture state, route state and application-wide background updates being coupled. The Home shell now updates fractional background mood through a `ValueNotifier` and confines per-frame painting to the background. The four tab pages are retained. A swipe updates the route on horizontal scroll end; a route-driven jump runs only when the external tab actually changes. A profile edit during an active drag no longer snaps the controller back.

Automated regression: hold a drag beyond half a page, update the profile, confirm the fractional page and retained shell remain unchanged, then release and confirm the Saved route after settling. This passes. It establishes behavior; it is not a frame-time benchmark.

The completion effect uses one 2.8-second animation controller. Visual crest and settle fractions correspond to 800 ms and 930 ms; light feedback starts the effect, then medium and selection feedback follow those thresholds. Reduced Motion uses the settled state, and sound/haptic preferences control feedback. The Cognein spring deck and birthday ruler use the reference motion implementation with HolyHim's palette.

**No device frame times or haptic precision measurement is claimed.** The signed build is installed and running over localNetwork. Apple’s UI-test connection is currently blocked at device preparation, so automated swipe trace capture has not completed. Compare native glass at rest and while scrolling; inspect 120 Hz responsiveness on the iPhone 14 Pro Max and the requested Reduce Motion/Transparency settings.
